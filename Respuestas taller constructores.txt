1. Análisis de Constructores (Parte C.1)
Habitacion(int n, String t) y Habitacion(int numero, String tipo)

¿Pueden existir al mismo tiempo?: No.

Justificación: Tienen exactamente la misma firma (int, String). Para Java, los nombres de los parámetros no diferencian la firma.

Habitacion(String tipo, int numero)

¿Puede coexistir?: Sí.

Justificación: Su firma es diferente (String, int) al invertir el orden de los tipos.

Habitacion(int numero)

¿Puede coexistir?: Sí.

Justificación: Su firma es única al recibir un único parámetro de tipo int.

2. Preguntas de Comprensión
¿Qué diferencias hay entre un constructor y un método? Menciona al menos tres.

El constructor tiene el mismo nombre de la clase y no tiene tipo de retorno; el método tiene un nombre arbitrario y exige un tipo de retorno (o void).

El constructor se ejecuta automáticamente al usar new; el método se invoca explícitamente sobre un objeto existente.

El constructor inicializa el estado del objeto al nacer; el método define acciones o comportamientos durante su ciclo de vida.

Respuestas

1.-El constructor se llama igual que la clase y no tiene tipo de retorno; el método tiene nombre libre y exige un tipo de retorno 

-El constructor se ejecuta automáticamente al usar new; el método se llama manualmente sobre un objeto existente.

-El constructor inicializa el estado del objeto; el método define acciones o comportamientos.

2.dejó de compilar: Java elimina el constructor vacío automático al crear uno con datos. Se soluciona agregándolo manualmente

3.Escribir peso = peso; sin this: Sí compila, pero el atributo queda en 0.0 por confusión de nombres this es obligatorio para diferenciarlos.

4.Firma y tipo de retorno: La firma es el nombre y sus parámetros. El tipo de retorno no sirve para distinguir métodos porque al llamar un método a veces no se usa su resultado, generando ambigüedad para el compilador.
